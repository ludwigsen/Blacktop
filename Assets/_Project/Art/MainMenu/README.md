# Main-menu prototype art

The two supplied concepts are copied unchanged as Fields/Downtown-Day.png and Fields/Campus-GoldenHour.png. The built-in image_gen tool generated Fields/Downtown-Dusk.png and Fields/Campus-Morning.png using both supplied concepts as references, with the intended reference called out in each prompt. All four source images are 1672 × 941 pixels. No native 4K resolution is claimed. These are concept menu backdrops, not captures of the playable Unity venues; campus is not a newly implemented venue.

Fonts/BlacktopProDuo.ttf is the owner's supplied font. Fonts/BarlowCondensed-SemiBold.ttf comes from [Google Fonts](https://github.com/google/fonts/blob/main/ofl/barlowcondensed/BarlowCondensed-SemiBold.ttf); its OFL license is included in Fonts/OFL.txt. The setup utility creates and prewarms the accompanying TMP SDF assets. It does not change the scorebug's font theme.

Preserve chain link fence on graffiti-covered low concrete wall, benches, big mature trees, neighborhood brick buildings and subtle white field boundary lines. New lighting: last light after sunset, blue violet sky, warm park lamps, believable city window glow, relaxed gritty neighborhood atmosphere. Detailed realistic game concept painting matching reference quality. Field stays empty, no players, no people, no goals, no helmets, no text, no logos, no watermarks, no UI. Broad uncluttered grass foreground and panoramic skyline. Not a stadium. Output one landscape image.
